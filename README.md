# Project-R

로켓단 / 소프트웨어융합학과 / 김관용 / 게임콘텐츠 트랙

1부터 25까지의 숫자를 순서대로 선택하는 웹 게임입니다. 현재 버전은 **프론트엔드 프로토타입**이며, 참가자 등록·서버 기록 저장·공유 랭킹은 아직 구현하지 않았습니다.

## 실행

- 별도 설치 없이 `index.html`을 브라우저로 열어 실행할 수 있습니다.
- Node.js가 있으면 프로젝트 폴더에서 `npm start` 후 `http://127.0.0.1:4173`에 접속할 수 있습니다. `npm install`은 필요하지 않습니다.
- 위 서버는 로컬 화면 확인용 정적 서버입니다. 기록 저장용 백엔드가 아닙니다.
- 테스트: `npm test` (Node.js 18 이상 권장).

## 구현 기능

- 닉네임 입력 형식 검사: 한글 완성형·영문·숫자 2~10자. 금칙어 검사와 참가자 등록은 미구현.
- 3초 카운트다운 후 무작위 5×5 숫자판 표시.
- 1~25 순서 판정, 정답 버튼 비활성화, 오답 피드백.
- `performance.now()`를 이용한 경과 시간 측정. 표시 단위는 초, 소수 셋째 자리.
- 결과 표시, 같은 닉네임으로 재도전, 처음으로 돌아가기.
- 계획서 와이어프레임 기반의 흰 배경·사각 테두리·기본 버튼, 모바일 화면 대응과 키보드 포커스 표시.
- 모바일·발표용 랭킹 화면의 배치와 화면 이동. 실제 순위, 최고 기록, QR 코드, 자동 갱신은 미구현이며 준비 중 상태를 표시합니다.

닉네임과 이번 기록은 메모리에서만 관리하므로 새로고침하면 초기화됩니다. 백그라운드 탭에서도 플레이 시간은 계속 흐릅니다. 브라우저에서 측정한 기록에 대한 조작 방지는 구현하지 않았습니다.

## 파일과 주요 설계

| 파일 | 역할 |
| --- | --- |
| `index.html` | 시작·게임·결과 화면 |
| `css/style.css` | 화면 디자인 및 반응형 배치 |
| `js/game.js` | Fisher–Yates 섞기, 게임 상태, 순서 판정, 시간 계산 |
| `js/app.js` | DOM 구성, 카운트다운, 화면 전환, 사용자 입력 |
| `tools/serve.cjs` | 외부 패키지 없는 로컬 정적 서버 |
| `tests/game.test.cjs` | 숫자판·입력·시간·초기화 검증 |

상태 흐름: `idle → countdown → playing → finished`. 재도전은 `countdown`으로, 처음으로 돌아가기는 `idle`로 초기화합니다. 게임 규칙과 화면 처리를 분리하여 백엔드 연동 시 규칙 변경을 줄이도록 구성했습니다.

## 보고서에서 설명할 코드

1. `createShuffledNumbers()` - 중복·누락 없는 숫자 생성 및 무작위 배치.
2. `NumberGame.select()` - 진행 상태 확인, 순서 판정, 종료 조건.
3. `NumberGame.start()`, `elapsedMs`, `reset()` - 측정 시작, 기록 고정, 상태 초기화.
4. `beginGame()`, `finishGame()` - 실제 화면과 게임 상태의 연결.
