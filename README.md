##Project-R

RankMaster
"랭킹에 도전하세요"
JavaScript, NodeJs Based Single-player record-breaking game

주요 파일 요약
| `index.html` | 시작/게임/결과 화면 |
| `css/style.css` | 화면 디자인 및 반응형 배치 |
| `js/game.js` | Fisher–Yates 섞기, 게임 상태, 순서 판정, 시간 계산 |
| `js/app.js` | DOM 구성, 카운트다운, 화면 전환, 사용자 입력 |
| `tools/serve.cjs` | 외부 패키지 없는 로컬 정적 서버 |
| `tests/game.test.cjs` | 숫자판·입력·시간·초기화 검증 |
